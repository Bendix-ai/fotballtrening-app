# App Store Metadata — FotballTrening

## iOS App Store

**Appnavn:** FotballTrening

**Undertittel:** Treningsapp for fotballklubber

**Kampanjetekst (maks 170 tegn):**
Tren smartere med strukturerte fotballøvelser, spor fremgang og konkurrer med lagkamerater!

**Beskrivelse:**
FotballTrening er den ultimate treningsappen for unge fotballspillere og deres trenere. Appen gir tilgang til et stort bibliotek av fotballøvelser tilpasset ulike ferdighetsnivåer, slik at spillere kan trene på egenhånd og spore fremgangen sin.

Funksjoner:
- Strukturerte fotballøvelser med instruksjoner og video
- Poengbasert system som motiverer til daglig trening
- Toppliste — konkurrer med lagkamerater og klubben
- Streak-system for å bygge gode treningsvaner
- Oppnåelser og badges for milepæler
- Trenerpanel for å administrere spillere og øvelser
- Øvelsesbutikk med delte øvelser fra andre klubber
- Rapporter og statistikk for trenere

Perfekt for:
- Fotballspillere (8-18 år) som vil bli bedre
- Trenere som vil strukturere egentrening
- Klubber som vil øke engasjementet

**Nøkkelord:** fotball,trening,øvelser,fotballtrening,leaderboard,streak,klubb,sport,barn,ungdom

**Kategori:** Sport
**Underkategori:** Helse og trening

**Aldersgrense:** 4+ (ingen stødende innhold)
