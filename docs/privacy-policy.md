# Personvernerklæring — FotballTrening

*Sist oppdatert: Februar 2026*

## 1. Introduksjon

FotballTrening ("vi", "oss", "vår") tar personvernet ditt på alvor. Denne personvernerklæringen forklarer hvordan vi samler inn, bruker og beskytter personopplysningene dine når du bruker FotballTrening-appen ("Tjenesten").

## 2. Hvilke opplysninger vi samler inn

### 2.1 Opplysninger du gir oss
- **Kontoinformasjon:** Brukernavn, visningsnavn, e-postadresse (kun for trenere/admin)
- **Klubbtilknytning:** Klubb, årgang og lag
- **Treningsdata:** Fullførte øvelser, poeng og streaker

### 2.2 Opplysninger vi samler inn automatisk
- **Bruksdata:** Hvilke funksjoner du bruker, når du bruker appen
- **Enhetsdata:** Operativsystem, appversjon
- **Feilrapporter:** Anonymiserte krasjrapporter via Sentry

### 2.3 Opplysninger vi IKKE samler inn
- Posisjonsdata (GPS)
- Kontakter eller adressebok
- Bilder eller kamera (med mindre du laster opp profilbilde)
- Helsedata
- Betalingsinformasjon

## 3. Hvordan vi bruker opplysningene

Vi bruker opplysningene dine til å:
- Levere og forbedre Tjenesten
- Vise din fremgang og plassering på topplisten
- La trenere administrere spillere og øvelser
- Sende varsler om trening (kun hvis du har aktivert dette)
- Analysere bruksmønstre for å forbedre appen (anonymisert)

## 4. Deling av opplysninger

Vi deler **ikke** personopplysningene dine med tredjeparter, med unntak av:
- **Supabase (databehandler):** Hosting av database og autentisering
- **Sentry (feilrapportering):** Anonymiserte krasjrapporter
- **Apple/Google:** Ved kjøp via App Store/Google Play

Vi selger aldri personopplysningene dine.

## 5. Datalagring og sikkerhet

- Data lagres i Supabase (EU-baserte servere der tilgjengelig)
- Alle data overføres kryptert (HTTPS/TLS)
- Passord er hashet og kan ikke leses av oss
- Row Level Security (RLS) sikrer at spillere kun ser egne data

## 6. Barns personvern

FotballTrening er beregnet for bruk av barn under 18 år under veiledning av foreldre/trenere. Vi samler ikke inn mer data enn det som er nødvendig for tjenesten. Barn opprettes som spillere av en trener/admin, og kontoen krever ikke e-postadresse.

Foreldre kan når som helst be om innsyn i eller sletting av barnets data ved å kontakte treneren eller oss direkte.

## 7. Dine rettigheter (GDPR)

Du har rett til å:
- **Se** dine personopplysninger
- **Rette** uriktige opplysninger
- **Slette** kontoen din og alle tilknyttede data
- **Eksportere** dine data i et lesbart format
- **Protestere** mot behandling av dine data

Kontakt oss for å utøve disse rettighetene.

## 8. Informasjonskapsler og sporing

Appen bruker ikke informasjonskapsler. Vi bruker enkel analysedata (anonymisert) for å forbedre tjenesten.

## 9. Endringer i personvernerklæringen

Vi kan oppdatere denne erklæringen fra tid til annen. Vesentlige endringer vil bli varslet i appen.
